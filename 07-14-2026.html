Command Center

Multi-race operational overview for ROC supervisors — one interface covering all ongoing events, live incident feeds, athlete counts, and a global race map.

  • Single view of all active races — no more switching between systems during race day
  • Live incident feed with dispatch shortcuts, race clock, and weather per event
  • Global race map and directory covering all upcoming and finished events
ⓘ  Main UI screens complete. Integration and the incident creation flow are next, based on feedback from Keats McGonigal.

Incident View

Screens for the end-to-end incident lifecycle — from a field report to command-center resolution — with a live course map and full athlete medical context.

  • Field-to-command in one flow: staff report incidents on mobile; coordinators manage them from the web command center on a live course map
  • Full medical context at every step, from first report through to resolution
  • Real-time resource tracking — medics, ambulances, helicopters, and vehicles, per race
  • V1 incident types: Medical, Weather, Transportation, and Others
ⓘ  Screens are complete but not yet integrated. Next sprint: integration with real data for incident creation and viewing, on both the app and the web command center.

  • Six languages live today: English, Spanish, German, French, Italian, and Portuguese (BR)
  • Language selector lives under Account Settings → Language

Testing & Adoption Planning

01
Testing Scope — First Session

All participants of this meeting will be invited to the first testing session, since it covers a general flow — user management, event and athlete pages, communications, and broadcasting.

Module Description Potential TTX Alignment
Home Page Central operational dashboard providing a real-time overview of active races, event status, and quick access to key operational tools. Event Operations, Command Center Operations
Account Management Allows users to manage profiles, roles, permissions, and access credentials. Supports the role-based access model required for event operations. Administrative Onboarding (TTX #1)
Race Page Provides a complete view of a specific event, including race details, course information, schedules, start times, and event-related resources. Administrative Onboarding, Event Operations
Edit Race Allows authorized users to update race configuration, locations, qualifier settings, event information, and supporting documentation in real time. Administrative Onboarding, Event Setup
Athlete Page Provides access to athlete records, race participation information, emergency contacts, and related athlete data. Event Operations, Medical Operations
Chat & Live Communications Enables real-time messaging and coordination across operational teams before and during an event. Communications (TTX #2)
Broadcasting 1.0 Provides the ability to distribute operational updates, notifications, and situational information to defined user groups. Communications (TTX #2), Event Operations

› Once specific-feature testing starts (Incident Management, PCR), we'll move to focus groups with just the team responsible for each area.

02
First Session — Structure & Plan

Aligned with James Hines and John Bertsch: since this first session covers a general flow, it's open to everyone from the bi-weekly update meetings. Specific-feature sessions come later, as focus groups per responsible team.

Format & Timing
  • Requesting an exclusive 1-hour slot — our current 30-minute bi-weekly slot isn't enough to complete the main flows
  • Once Pat and Keats McGonigal have the test event set up, we'll find a time that works for all participants — targeting next week
Session Plan
  • Before the session: all users have the app downloaded and permissions granted for the test event
  • During the session: users complete guided tasks in the app — e.g. viewing the course overview, sending a chat message to a specific staff type, checking an athlete's emergency contact
  • Leo and Hyago join to monitor logs on LogRocket in real time
  • Feedback is collected live from participants using a tool like a Miro board
  • Initial session material will be shared once ready

› For now, we're focused on the app. Once the incident management flow is concluded, Command Center and Global Dashboard will be tested on web in a separate session.
